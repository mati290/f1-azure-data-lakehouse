# Dashboard Dataset

## Data Source

- Provider: Jolpica F1 API
- API: https://api.jolpi.ca/ergast/f1/
- Seasons: 2021–2025
- Format: Apache Parquet
- Source layer: Gold Analytics

## Transformations

The original data has been cleaned, normalized,
deduplicated, modeled into a dimensional schema,
joined into an analytical dataset and exported
as a Parquet snapshot.
